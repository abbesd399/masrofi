# Masrofi (مصروفي) 📱💰
### Smart Family Finance & AI Bill Management Prototype (iOS 18 & Android Material 3)
### استوديو المعاينة التفاعلي وإدارة مصاريف العائلة بالذكاء الاصطناعي

---

## 🌟 Overview / نظرة عامة

**Masrofi (مصروفي)** is a high-fidelity, interactive mobile application UI prototype and desktop preview studio designed specifically for the **Algerian household financial context** (DZD د.ج, Arabic RTL, French, and English). 

Built to top-tier **2026 Fintech standards** (inspired by Revolut 10, Apple Card/Wallet, Mobbin, and Dribbble), it completely eliminates primitive emojis in favor of crisp vector SVG iconography, authentic frosted glassmorphism, multi-stop mesh gradients, and interactive simulations.

---

## ✨ Key Features / المميزات الرئيسية

### 1. 🖥️ Interactive Desktop Preview Studio
- **Dual OS System**: Seamless live toggle between **iOS 18 (Apple HIG / iPhone 16 Pro)** and **Android (Material Design 3 / Pixel 9 Pro)**.
- **Side-by-Side Dual View**: Inspect and test both iOS and Android views simultaneously with synchronized state.
- **Interactive Dynamic Island**: Tap the island or trigger notifications to see it expand with live bill alerts.
- **Theme & Direction Switcher**: Instant switching between **Dark Mode** and **Light Mode**, plus **العربية (RTL)**, **Français (LTR)**, and **English (LTR)**.
- **Live Scenario Simulators**: Quick actions to trigger Month-Start alerts, AI bill scans, and simulated family purchases.

### 2. 🇩🇿 Full Algerian Financial Profile
- **Currency**: Algerian Dinar (**DZD / د.ج**).
- **Pre-seeded Bills & Obligations**:
  - Sonelgaz electricity & gas (سونلغاز للتوزيع)
  - Algérie Télécom Idom Fibre (اتصالات الجزائر)
  - SEAAL water (سيال)
  - SAA Automobile Insurance (الشركة الوطنية للتأمين)
  - Contrôle Technique (الفحص التقني للسيارات)
  - Vignette Automobile 2027 (قسيمة السيارات)
  - Naftal Fuel & Vidange (نفطال)
- **Family Profile**: Amine (Father), Karima (Mother), Rayan (Son), and Sarah (Daughter).
- **Vehicle Profile**: Dacia Sandero Stepway with 3D interactive tilting card, odometer tracker, and oil change countdown.

### 3. 📷 Central AI Camera Scanner (الماسح الذكي)
- MagicPattern perspective grid with high-tech laser scan animation.
- Web Audio API zero-asset synthetic haptic audio clicks, laser sweeps, and success chimes.
- 4 Algerian presets:
  1. *Sonelgaz electric invoice*
  2. *SAA car insurance policy*
  3. *Naftal fuel ticket*
  4. *Uno supermarket receipt*
- Live simulated OCR text extraction, duplicate check, and price hike detection with 1-tap budget confirmation.

### 4. 👥 Family Shared Wallet & Smart Grocery Cart
- **Dynamic Family Filter**: Filter the transactions feed by family member with live count badges and zero-spend empty states.
- **AI Shared Grocery Cart**: Estimate the total cost of groceries before visiting the supermarket and preview its impact on remaining salary.

## 🚀 How to Run Locally / التشغيل المحلي

### Option 1: Direct in Browser (Zero Installation)
Simply double-click [`index.html`](index.html) to open the interactive studio in any modern browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Node.js)
```bash
node server.js
```
Then visit: **`http://localhost:3000/`**

### Running the Test Suite
```bash
node test_suite.js
```
